# STEAD example data licence

These samples are derived from the Stanford Earthquake Dataset (STEAD) by S. Mostafa Mousavi, Yixiao Sheng, Weiqiang Zhu and Gregory C. Beroza. [Upstream licence](https://github.com/smousavi05/STEAD/blob/master/LICENSE) · [STEAD article](https://doi.org/10.1109/ACCESS.2019.2947848).

The example data use [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes comprise subset selection, lossless HDF5 repackaging, metadata selection, integer pick representation and the `-1` encoding for absent noise picks. See the [project data notice](../../DATA_LICENSE.md).
